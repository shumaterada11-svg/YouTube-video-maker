# ワン高物語 第1話：Gemini 素材づくりガイド

ブラウザ版 Gemini（gemini.google.com）でピクサー風の絵と動画を作り、`story_maker.py` で声・字幕・BGM を付けて仕上げます。
Mac の Claude（Claude in Chrome）に「`gemini_prompts/wan_high_ep1.md` の通りに素材を作って」と頼めば、この手順で進められます。

## 全体の流れ

1. キャラクター設定画を作る（見た目をそろえるための見本）
2. 場面ごとの絵（12枚＋α）を、設定画を添付して作る
3. 大事な場面だけ、その絵を動画にする（1日に作れる本数に上限があるため）
4. 素材を決まった名前で保存して、`story_maker.py` を実行する

## 保存先とファイル名

```
デスクトップ/YouTube動画/wan-high-ep1/素材/
├ キャラ/kotaro.png など   … 設定画（ツールは使わない。Gemini に添付する見本）
├ shot01.png 〜 shot12.png  … 場面の絵
├ shot07.mp4 など           … 動画にした場面（同じ番号の .png より優先）
├ shot11_2.png / .mp4       … 場面11の2つ目のセリフ（結果発表）から切り替える絵
└ thumbnail.png             … サムネイル（任意）
```

- 素材がない場面は、これまでのプログラムの絵で描かれます。少しずつ差し替えられます。
- 横長の絵や動画でも使えます（ぼかした背景の上に置かれます）。縦長 9:16 で作るのがいちばんきれいです。
- 動画の音声は使いません。声・BGM・効果音はツールが付けます。

---

## 共通スタイル（すべてのプロンプトの先頭に付ける）

```
ピクサー映画のような3DCGアニメーション。ふわふわでリアルな毛並み、やわらかい映画的なライティング、明るく温かい色。
犬たちは二足歩行で、人間の高校生のように制服を着ている。縦長9:16の構図。
画面内に文字・看板の文字・字幕は入れない。
```

## キャラクターの説明（プロンプトに貼る）

- **コタロウ**：明るい茶色のミニチュアダックスフントの男子高校生。胴が長く足が短い。大きな丸メガネ。紺のブレザー、白シャツ、赤いネクタイ、グレーのズボン、茶色のローファー。内気で照れ屋、少し猫背。
- **レオン**：アプリコット色のトイプードルの男子高校生。頭の上にサングラス。紺のブレザーの前を開け、シャツの胸元から金のネックレス。白いスニーカー。陽気でノリの軽い笑顔。
- **ゴウ**：黒いピットブルの男子高校生。大柄で筋肉質。左目の上に小さな傷。丈の長い濃紺の学ラン（長ラン）に金ボタン、赤いインナー。クールで無口だが、目は優しい。
- **チア部**：オレンジ色のふわふわなポメラニアンの女子3匹。白とオレンジのチアユニフォーム、オレンジのプリーツスカート、黄色のポンポン。頭のリボンは赤・青・黄で1匹ずつ色違い。
- **不良たち**：黒い学ランのブルドッグ2匹。1匹はグレーで白いマスク、もう1匹は茶色で黒いリーゼント。
- **学校**：時計塔のある白い校舎の高校。

## 手順1：キャラクター設定画（`キャラ/` に保存）

キャラごとに1枚ずつ作ります。気に入るまで作り直してOK。ここで決めた見た目が全場面の基準になります。

```
（共通スタイル）
キャラクター設定画。白い背景に、同じキャラクターの正面・横向き・後ろ姿の全身を並べる。
（キャラクターの説明をここに貼る）
```

保存名：`kotaro.png`、`leon.png`、`gou.png`、`poms.png`（3匹まとめて）、`yanki.png`（2匹まとめて）

## 手順4：仕上げ

```bash
cd ~/youtube-video-maker && source venv/bin/activate
python story_maker.py --story stories/wan_high_ep1.json
```

`デスクトップ/YouTube動画/wan-high-ep1/素材/` が自動で読み込まれます。

## うまくいかないとき

- **キャラの見た目がぶれる**：設定画を必ず添付し、「添付したキャラクターと同じ見た目で」と書く。ぶれた絵は作り直す。
- **文字が入ってしまう**：「文字・看板の文字は入れない」を強調して作り直す。字幕や見出しはツールが付けます。
- **横長になってしまう**：そのまま使えます（ぼかした背景の上に置かれます）。
